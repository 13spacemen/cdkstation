# Google Code project page for CDKstation (`spacestation13`)

This branch holds what survives of the project's Google Code page, `http://code.google.com/p/spacestation13/`
(SVN `http://spacestation13.googlecode.com/svn`). Nothing here is from SVN, and it shares no history with the converted
branches (`master`, `svn-final-import`, `svn-trunk`, `wiki`, `svn-mirror`).

Downloaded 2026-11-04 from the Google Code Archive (`https://code.google.com/archive/p/spacestation13`) and the Wayback
Machine. Files are byte-for-byte as served.

## The project

- **Summary:** Space Station 13 - a BYOND game
- **Description:** An independent development branch of the BYOND game, based on the public release revision (r4407)
  of Goon Station 13.
- **Owners** (2010-12-20): andrewmontagne, caiganmythfang, Bon.Toledo. The page also shows 1 committer, not named
  (probably Skiedrake, who made r55–r73), and 0 contributors.
- **Code license:** GNU GPL v3
- **Content license:** Creative Commons 3.0 BY-SA. `project.json` gives the code `cc3-by-nd`, which the archive's own
  table maps to BY-SA, as the 2010 page also shows.
- **Labels:** space, station, 13, byond
- **Stars:** 8
- **Issues and downloads:** none. The project never had any.
